# 旅程ドラフト(札幌・小樽)

> **方針**: Day 1 札幌着 → 札幌市内、Day 2 小樽日帰り、Day 3 札幌で締めて帰路。
> 飛行機の時間が決まり次第、Day 1 と Day 3 を調整。

## Day 1 — 2026/07/22(水) 札幌着・札幌グランドホテル泊

- [ ] 出発空港: HND or NRT(価格次第)
- [ ] フライト:                → 新千歳着
- [ ] 新千歳空港 → 札幌駅(JR快速エアポート 約37分)
- [ ] 宿(札幌グランドホテル)に荷物預け、または15:00以降ならチェックイン
- [ ] 昼食: **麺屋 彩未**(味噌ラーメン・行列)or 別タイミングへ
- [ ] 午後: 大通公園・テレビ塔・二条市場
- [ ] **チェックイン 15:00以降**(札幌駅地下直結・徒歩10分)
- [ ] 夕食: **フクロウ亭**(ジンギスカン・要予約)
- [ ] 夜: すすきの散策 or 藻岩山で夜景

## Day 2 — 2026/07/23(木) 小樽日帰り

- [ ] 朝食: **二条市場(朝市)で海鮮丼** ← 朝市候補その1
- [ ] 札幌駅 → 小樽駅(JR 約32分)
- [ ] 三角市場で軽食 or 海鮮丼 ← 朝市候補その2(両方行くなら軽めで)
- [ ] 小樽運河で写真
- [ ] 堺町通り散策(北一硝子、オルゴール堂、LeTAO 本店)
- [ ] 昼食: 寿司屋通りで寿司
- [ ] 午後: 天狗山ロープウェイ or カフェでゆっくり
- [ ] 夕方: 運河の夜景(ガス灯)を見て札幌へ戻る
- [ ] 夕食: **スープカレー(店未定)** or 大通ビアガーデン
- [ ] 夜: ホテルでゆっくり

## Day 3 — 2026/07/24(金) 札幌・帰路

- [ ] **チェックアウト 〜11:00**(札幌グランドホテル)
- [ ] 朝食: 素泊りなので外食(札幌駅構内・地下街など)
- [ ] チェックアウト後も荷物は預かってもらえることが多い → フロントで確認
- [ ] 午前: 北海道神宮 + 円山公園で散歩、もしくは白い恋人パーク
- [ ] 昼食: 残しておきたいジャンル(海鮮丼 / スープカレー / 寿司 など)
- [ ] お土産購入(札幌駅・新千歳空港)
- [ ] 札幌駅 → 新千歳空港(JR 約37分)
- [ ] フライト(**15:00 以降推奨**):                → 帰宅

## 予約・確認事項

- [ ] 飛行機(往復)
- [ ] **フクロウ亭**(ジンギスカン・要予約)
- [ ] スープカレー店を確定
- [ ] 麺屋彩未の営業時間と組み込みタイミング
- [ ] 朝市はどちらメインで行くか(二条市場 / 三角市場)
- [ ] 藻岩山ロープウェイ営業時間
- [ ] 天狗山ロープウェイ営業時間
- [ ] 大通ビアガーデンの開催期間

## バッファ・代替案
