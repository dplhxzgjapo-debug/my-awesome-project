# 旅程ドラフト(札幌・小樽)

> **方針**: Day 1 札幌着 → 札幌市内、Day 2 小樽日帰り、Day 3 札幌で締めて帰路。
> 飛行機の時間が決まり次第、Day 1 と Day 3 を調整。

## Day 1 — 2026/07/22(水) 札幌着・札幌泊

- [ ] 出発空港:
- [ ] フライト:                → 新千歳着
- [ ] 新千歳空港 → 札幌駅(JR快速エアポート 約37分)
- [ ] 宿に荷物を預ける(チェックイン前ならフロント預け)
- [ ] 昼食: 札幌で味噌ラーメン or スープカレー
- [ ] 午後: 大通公園・テレビ塔・二条市場
- [ ] チェックイン
- [ ] 夕食: ジンギスカン or 大通ビアガーデン(開催されていれば)
- [ ] 夜: すすきの散策 or 藻岩山で夜景

## Day 2 — 2026/07/23(木) 小樽日帰り

- [ ] 朝食: 宿 or 札幌で軽く
- [ ] 札幌駅 → 小樽駅(JR 約32分)
- [ ] 三角市場で軽食(まだ余裕あれば)
- [ ] 小樽運河で写真
- [ ] 堺町通り散策(北一硝子、オルゴール堂、LeTAO 本店)
- [ ] 昼食: 寿司屋通りで寿司
- [ ] 午後: 天狗山ロープウェイ or カフェでゆっくり
- [ ] 夕方: 運河の夜景(ガス灯)を見て札幌へ戻る
- [ ] 夕食: 札幌に戻ってから(海鮮 or ラーメンなど未食ジャンル)
- [ ] 夜: ホテルでゆっくり

## Day 3 — 2026/07/24(金) 札幌・帰路

- [ ] チェックアウト前に朝食
- [ ] 荷物を宿に預ける(チェックアウト後でも可なところが多い)
- [ ] 午前: 北海道神宮 + 円山公園で散歩、もしくは白い恋人パーク
- [ ] 昼食: 残しておきたいジャンル(海鮮丼 / スープカレー / 寿司 など)
- [ ] お土産購入(札幌駅・新千歳空港)
- [ ] 札幌駅 → 新千歳空港(JR 約37分)
- [ ] フライト:                → 帰宅
