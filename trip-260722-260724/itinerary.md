# 旅程ドラフト(札幌・小樽)

> **方針**: Day 1 札幌着 → 札幌市内、Day 2 小樽日帰り、Day 3 札幌で締めて帰路。
> 飛行機の時間が決まり次第、Day 1 と Day 3 を調整。

- [ ] 5:30 ごろ 自宅出発(成田までの所要次第で調整)
- [ ] 7:00 NRT **第1ターミナル 南ウィング1階** 到着・受付・保安検査
- [ ] **8:45 NRT 発 MM563** → **10:35 ごろ CTS 着**
- [ ] 11:00 JR 新千歳空港駅 → **快速エアポート 37 分**
- [ ] 12:00 札幌駅着 → ホテルに荷物預け
- [ ] 12:30 ランチ: 札幌中心部で味噌ラーメン(すみれ 札幌駅店 / けやき 等)
  ※ 彩未は Day 3 ランチに回す
- [ ] 14:30 大通公園・テレビ塔・二条市場散策
- [ ] **15:00 以降チェックイン** 札幌グランドホテル

## Day 2 — 2026/07/23(木) 小樽日帰り

> **最優先**: ちいかわもぐもぐ本舗 小樽店(7/18 オープン・訪問は開店から5日目)。混雑必至なので朝一直行。
> **〆**: 札幌帰着後に佐藤本店で夜パフェ。

- [ ] 朝食: 札幌の宿出発前 or 札幌駅で軽く(時間優先)
- [ ] 8:30 ごろ 札幌駅 → 小樽駅(JR 約32分)
- [ ] **9:30〜 ちいかわもぐもぐ本舗・ちいかわベビーカステラ**(堺町通り)
  - 当日の入店予約・整理券ルールに従う(出発前に公式 X で要最終確認)
- [ ] 11:00 堺町通り散策(北一硝子・オルゴール堂・LeTAO 本店)
- [ ] 12:30 寿司屋通りでランチ寿司
- [ ] 14:00 小樽運河(昼の散策・写真)
- [ ] 15:30 三角市場 or 天狗山ロープウェイ(余裕あれば)
- [ ] 17:00 カフェ or 海猫屋で早めディナー
- [ ] 19:00 運河に戻ってガス灯点灯 → 写真
- [ ] 21:00 小樽駅 → 札幌駅(JR 約32分)
- [ ] 21:30 札幌駅着 → すすきの方面へ移動
- [ ] **22:00 パフェ、珈琲、酒、佐藤 本店**(2-3F)で夜パフェ

- [ ] 23:30 ごろ ホテル戻り
