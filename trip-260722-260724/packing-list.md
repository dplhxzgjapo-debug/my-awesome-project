# 持ち物リスト(札幌・小樽 7月下旬・2泊3日)

> 7月下旬の北海道は最高 25°C・最低 18°C 前後。**朝晩は肌寒い・冷房も効く**ので羽織り必須。

## 必需品

- [ ] 財布(現金・カード)
- [ ] スマホ・充電器・モバイルバッテリー
- [ ] 身分証明書 / 保険証
- [ ] 鍵
- [ ] 予約確認書(飛行機・宿・レストラン)
- [ ] eチケット控え

## 衣類(2泊3日)

- [ ] 下着 ×3
- [ ] 靴下 ×3
- [ ] Tシャツ / トップス ×3
- [ ] パンツ / ボトムス ×2
- [ ] **羽織りもの(カーディガン・薄手パーカー)**:夜・冷房・ロープウェイ山頂用
- [ ] 薄手の長袖 1枚(藻岩山・天狗山の夜は冷える)
- [ ] パジャマ / 部屋着
- [ ] 折りたたみ傘(にわか雨対策)
- [ ] 歩きやすい靴(運河・堺町通りは結構歩く)

## 洗面・身だしなみ

- [ ] 歯ブラシ・歯磨き粉(宿アメニティ次第)
- [ ] スキンケア
- [ ] ヘアケア(ブラシ・ヘアアイロン等)
- [ ] **日焼け止め**(紫外線強い)
- [ ] リップ(乾燥対策)
- [ ] 制汗剤
- [ ] コンタクト / メガネ

## 健康

- [ ] 常備薬
- [ ] 絆創膏(歩きすぎ対策)
- [ ] 酔い止め(ロープウェイ・飛行機)
- [ ] 虫除け(円山公園・藻岩山で活躍)
- [ ] マスク

## 電子機器

- [ ] カメラ(SDカード・予備バッテリー)
- [ ] イヤホン
- [ ] 各種充電ケーブル
- [ ] (任意)三脚 or スマホスタンド:夜景写真用

## 彼女と一緒に楽しむもの

- [ ] (例)旅のしおりプリント
- [ ] (例)プレイリスト準備(移動中用)
- [ ] (例)カフェで使えるトランプ

## あると便利

- [ ] エコバッグ / サブバッグ(お土産用)
- [ ] ビニール袋(濡れ物・お菓子残り用)
- [ ] ウェットティッシュ
- [ ] 機内・JR用の軽食 / 飲み物

## LCC を使う場合の追加注意

- [ ] 機内持ち込みサイズと重量を事前計測
- [ ] 受託手荷物の事前申し込み(当日は割高)
- [ ] 液体物 100ml ルール
